# Task 4 - SQL Data Analysis

## Internship Task

This project demonstrates SQL skills by performing data analysis on the Sample Superstore dataset using SQLite Online.

## Objective

The objective of this task is to perform SQL queries to analyze sales data and extract meaningful business insights.

## Dataset

- Sample Superstore Dataset (CSV)

## Tools Used

- SQLite Online
- SQL
- GitHub

## SQL Operations Performed

- SELECT Statement
- WHERE Clause
- ORDER BY
- GROUP BY
- Aggregate Functions (SUM, AVG)
- Subqueries
- CREATE VIEW

## Queries Executed

1. Display all records.
2. Filter records for the West region.
3. Sort sales in descending order.
4. Calculate total sales by category.
5. Find the average profit.
6. Display records where sales are greater than the average sales.
7. Create a view to summarize total sales by category.

## Business Insights

- The West region contributes significantly to overall sales.
- Technology and Office Supplies categories generate high sales.
- SQL helps efficiently analyze large datasets and identify trends.
- Aggregate functions and views simplify business reporting.
